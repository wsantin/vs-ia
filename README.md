# Serverless Framework AWS TypeScript

## Pre-requisitos de desarrollo 📋

_Instalar los siguientes componentes_

```
nodejs
npm install g- serverless
```

_Instalar el siguiente IDE de desarrollo_

```
Visual Studio Code
```

## Desarrollo ⚙️

_Utilice el siguiente comando para validar la aplicación_

```
npm run start
```

## Pruebas unitarias 🛠️

_Utilice el siguiente comando para ejecutar las pruebas unitarias_

```
npm run test
```

## Despliegue 📦

_Utilizar la siguiente herramienta de despliegue:_

```
Jenkins | github
```
